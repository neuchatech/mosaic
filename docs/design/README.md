# V1 visual direction

`mosaic-gold-standard.png` is the approved V1 reference generated during the
product-design pass on 2026-08-30.

Use it to judge hierarchy and feel rather than copy every pixel:

- assistant-first entry point;
- warm editorial surface with restrained coral and moss accents;
- board imagery dominates controls;
- compact Explore / Collections / Activity navigation;
- filters and view settings open contextually;
- selection actions appear only when needed;
- collection context and minimap remain lightweight.

Avoid the MVP's always-visible wall of dropdowns, clipped oversized labels,
developer terminology, permanent status cards, and multiple competing primary
buttons.
